# 从评分器到《灯火归来》

早期以 36 个标准槽位组织训练材料。其中包含匹配原作、公开民谣替代与程序化替代；36 个槽位不等于取得 36 首原作。初期弱标签模型能区分原谱与噪音，但生成端的固定伴奏与节奏造成作品相似。

后续引入风格分桶、节奏模板、MMR 多样性重排、机械负例与声部特征。五首作品获得过同一听众的 60 / 50 / 40 / 70 / 30 分。这些是保留的数值锚点，其他文字反馈没有转换成虚构分数。

一度追求复杂节奏和高熵，产生听感混乱的候选；再加入严格声部限制，又出现旋律简单、缺乏记忆点的问题。由此转为法式浪漫钢琴织体：十六分十度琶音、主旋律回音动机、长句、高音区展开、踏板和力度呼吸。

听众认可过 E 小调片段的节奏与旋律，也认可 F 大调片段的舒展长音。后续保留有效动机，逐句修改回落和上升，形成《等你归来》《你的脚步》《远处的灯》等项目内原创片段。

最终保留《灯火归来》短版：

1. 《远处的灯》前两小节；
2. 一小节连接；
3. 《等你归来》开头约 5.14 秒；
4. 大调尾声。

其余试听音频、临时修改脚本、压缩传输包、重复云端回传目录和原始数据下载缓存，在 2026-11-11 的整理中删除。最终作品由独立事件谱保存，重建时不再需要旧版本。

最终曲目不是原曲转录，也不是通过某个高机器评分自动选出的作品。当前保留的 Critic 仍是待验证的研究组件。
