# 项目思路与当前边界

目标是把音乐创作变成可听、可修改、可积累反馈的闭环：生成候选 → 乐理与结构检查 → 试听 → 对具体时间段反馈 → 保留有效动机并局部修订。

最初提出的“神经科学沙盒”希望结合听觉预期、意外与解决、呼吸和张力。当前实现只使用符号音乐代理特征与少量人类反馈，没有建立经过神经数据验证的人脑模型。

## 当前保留的技术

1. 用 music21 分析主旋律和伴奏；提取意外度、和声张力、声部连接、呼吸、动机及节奏特征。
2. 用 GradientBoostingRegressor 学习弱监督扰动标签；增加机械重复、无解决跳进等负例。
3. 增加声部与音域特征，构成 33 维 Critic；区分技术底线与主观偏好。
4. 通过原始试听反馈修正“同质化”“无记忆点”“回落过短”“调式不符合期待”等问题。
5. 用明确的音符事件、动态、踏板和采样钢琴输出可复现的 MIDI/WAV。

## 创作中学到的偏好

- 保留可以哼唱的短动机，并安排真正的回答、变形和重现。
- 音域变化需要跨越数小节的方向感；不要每小节独立上升再下降。
- 长短交替、有停顿的旋律节奏，比固定八分音符或无目的碎音更符合本次听众偏好。
- 和弦标为大调并不保证听感为大调；旋律落点、低音与转折必须共同支持目标色彩。
- 流水伴奏服务于旋律，避免低频混浊和过度踏板。
